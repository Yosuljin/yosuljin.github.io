DOMAINE 01 / 04

Développement

Comprendre les systèmes en les construisant : Rust surtout, des moteurs écrits from scratch, des contrats entre programmes, et une documentation qu’on vérifie contre le code.

PÉRIMÈTRE

Cette page parle de technique. Les projets qui composent Aether sont présentés dans son dossier ; ici, seulement la manière de travailler et les chantiers qui en sortent.

開發

Construire pour comprendre.

Je préfère reconstruire que reproduire : un moteur réécrit depuis zéro apprend plus qu’un moteur emprunté. Chaque pièce garde son propre code, son propre rythme et ses propres épreuves.

  • 03la lumina — le langage de Lumina, .lum, son interpréteur et son shell.LANGAGE

Principes

La doc peut mentir. Une affirmation que le code dément est une faute : on vérifie contre les fichiers, pas l’inverse.

Un module s’ajoute. Retirez-le et lancez le produit : ce dont le cœur ne peut pas se passer n’est pas un module.

Ce qui se compte s’engendre. Les recensements sont produits depuis le code, jamais recopiés à la main.

Ce site, aussi.

Ces pages suivent la même méthode : tout ce qu’elles chargent vient du site lui-même.

  • 01HTML, CSS et modules JavaScript natifs : ni framework, ni étape de compilation.WEB
  • 02En FULL 3D, le monde en arrière-plan est rendu en WebGL par des shaders écrits pour le site ; le mode LITE l’éteint.WEBGL
  • 03Le son est synthétisé en direct par Web Audio : aucun fichier audio.SON
  • 04Polices auto-hébergées, aucune ressource tierce ; le code ne dépose aucun cookie et ne mesure pas l’audience (confidentialité).SOBRIÉTÉ
  • 05La préférence système « réduire les animations » est respectée : les animations automatiques s’arrêtent.ACCESSIBILITÉ
