ANoyau — Lumina et son corps

EN CONSTRUCTIONRUST · CHANTIER PRINCIPAL

TheHive

Le squelette matériel dans lequel Lumina réside et s’exécute.

Le plus petit système possible : noyau, pilotes, squelette et modules, pas une distribution complète. La production vise une machine dédiée, sans couche intermédiaire ; un banc virtuel sert à la conception et aux essais. Première fondation livrée : une durabilité déclarée et mesurable, où la fenêtre de perte après une coupure est lue dans le montage réel plutôt que supposée.

Ce n’est pas Lumina : c’est son corps et son habitat.

ARCHITECTURESYSTÈME COGNITIF · D89

Lumina

Le système cognitif, persona centrale du parc.

Un conscient, un inconscient fait de systèmes spécialisés, des lumens hétérogènes. Ses moteurs sont écrits pour elle, sans monoculture : elle ne réutilise pas la mémoire d’un autre agent. Sa forme complète se construit après les fondations de TheHive.

Ce n’est pas la lumina, qui est son langage.

Relié à TheHive la lumina reminiscence furu

PROTOTYPE ACTIFRUST · .LUM

la lumina

Un vrai langage de programmation, écrit en latin, conçu comme shell.

Pipelines typés et données structurées — listes, enregistrements, tables — plutôt que du texte brut. Un interpréteur en Rust presque sans dépendance : les seules bibliothèques externes sont les primitives cryptographiques (RustCrypto) qu’apporte Memoria pour reminiscence ; le moteur GPU reste optionnel. Le latin y est du vocabulaire technique, pas un ornement. Une suite de conformité exécute de vrais scripts et compare sorties et codes de sortie octet pour octet. C’est le shell par défaut de TheHive.

Ce n’est pas la persona Lumina.

Relié à TheHive Lumina Memoria (inscrit, pas un projet)

SPÉCIFICATIOND102 · AUCUN CODE ATTRIBUÉ

furu

Le moteur de sentience : moteur de rendu et base commune des futurs organes.

Tous les organes de perception et d’action de Lumina se construiront sur lui. Le premier organe nommé est la vision distante — voir à travers un drone —, qui ne le définit pas à elle seule. Ordre de travail : contrat général, premiers organes, frontière avec TheHive, emplacement du code, puis implémentation.

Ni mémoire, ni autopilote : le contrôle de vol restera un module distinct.

Relié à TheHive Lumina

EN TRANSITIOND90 · API OUVERTE

reminiscence

La mémoire propre, future, de Lumina.

Une implémentation de transition existe dans le dépôt du langage, avec trois verbes : memento, recordare, oblivisce. Son architecture et son API finales restent ouvertes ; TheHive devra lui fournir son substrat.

Ce n’est pas Memoria, qui figure parmi les inscrits.

Relié à Lumina TheHive Memoria (inscrit, pas un projet)

BProjets en code

ACTIFRUST · BANC D’ESSAI

AlmaS

Reconstruction Rust de l’Alma d’origine — l’œuvre d’un autre auteur, portée avec son accord —, devenue banc d’essai des modules.

Trois qualités, dans cet ordre : la mieux documentée, la meilleure pour les épreuves d’intégration, la plus stable. La méthode : rénover fidèlement d’abord, simplifier et optimiser ensuite — le S d’AlmaS veut dire Simplified.

Sa mémoire n’est pas reminiscence.

Relié à Greffe Lucarne

ACTIFRUST · VALPHA1.0

Linh

Agent portable de terrain, réécrit from scratch, et clé d’activation de TheHive.

Sans runtime asynchrone, avec des outils qui agissent réellement sur la machine et un essaim d’agents qu’elle orchestre elle-même. Persona et mémoire légères ; le fournisseur de modèle est une donnée, pas du code. Elle doit rester utilisable seule.

Ce n’est pas « l’intelligence » du parc : cette lecture appartient à une carte antérieure.

Relié à TheHive Greffe Net LinhMesh

ACTIFRUST · SOCLE NEUTRE

Greffe

Le contrat par lequel un module se greffe sur un agent — et les modules eux-mêmes.

Trois invariants : le cœur tourne sans aucun module ; l’absence d’un module produit un message clair, jamais un crash ; ajouter un module ne demande aucune modification du cœur. Un module est un programme séparé qui parle en lignes JSON sur ses flux standard : il peut être écrit dans n’importe quel langage.

Neutre : il n’appartient à aucun agent, pour qu’aucun n’ait à le recopier.

Relié à AlmaS Linh

ACTIFRUST · D103

Lucarne

La surface graphique hôte de la famille Alma — AlmaS, Alma, Rose, Linh et AlmaF —, avec AlmaS par défaut.

Une interface dont la surface est du SVG, engendrée en Rust et servie en local ; elle s’ouvre aujourd’hui dans une fenêtre d’application du navigateur, une fenêtre native est en chantier. Depuis D103, elle vise plusieurs sessions simultanées à très basse consommation mémoire — un objectif, pas encore une mesure. Les agents vivent dans la surface ; la surface ne vit pas dans un agent.

Ce n’est pas une fenêtre d’AlmaS : AlmaS en est la première occupante, pas la propriétaire.

Relié à AlmaS Linh

ACTIFRUST · SESSIONS

Net

Réutiliser proprement une session que j’ai ouverte moi-même, pour un client HTTP léger.

Ses limites sont mesurées et documentées, pas supposées. Piste ouverte, non décidée : un moteur de recherche natif plus léger.

Relié à Linh

OUVERTFLUTTER · YGGDRASIL

LinhMesh

Un réseau maillé décentralisé bâti sur Yggdrasil : application Android et client web.

Un réservoir d’idées pair-à-pair. Absorption dans Linh ou réécriture : non tranché, et non bloquant. Yggdrasil et Matrix y sont rangés pour plus tard.

Relié à Linh

OUTILSHELL · CC0

Temoin

Une garde sait-elle encore dire non ?

Une garde qui ne trouve rien est indiscernable d’une garde qui ne regarde rien : les deux rendent un vert. Temoin lui présente quatre cas dont la réponse est connue d’avance — périmètre fantôme, bac vide, témoin positif, témoin négatif.

05 / RÈGLES

Ce qui empêche la carte de mentir.

DISCIPLINE
01Décision ≠ idée.

La prospective peut chercher loin ; une décision structurante entre dans le registre Aether.

02Mesuré ≠ rapporté ≠ spéculé.

Les régimes restent visibles et ne se mélangent pas en silence.

03Fiche ≠ recensement.

Ce qui se compte est engendré depuis le code ; ce qui s’explique est écrit.

04Projet ≠ module.

Un gros module devient un projet lorsqu’il possède son propre cycle, ses épreuves et ses frontières.

05Récent > ancien.

Une décision amendée se lit dans sa dernière forme ; un texte ancien garde son régime historique au lieu d’être présenté comme actuel.

06Nommer ce qu’on ne sait pas.

Un blanc nommé coûte une ligne ; un blanc comblé par une supposition coûte une refonte.
